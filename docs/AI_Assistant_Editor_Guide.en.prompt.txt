RER-ENGINE: 2D/3D editor. Left sidebar = accordions. Viewport = scene. Entity properties = modal on entity click (not in sidebar).

ACCORDIONS (OPEN_ACCORDION): scenes | mundo | camera | resources | entities | ui | herramientas | controles

UI_LABELS_EN: Entity properties | Convert to Blueprint | Tools | Quick Build | Construction modal | Save

P: Create scene? → Accordion "Scenes" → "Create new scene" → Assign name in modal.
P: Load 3D model? → Accordion "Resources" → Accordion "Models" → Pick a category → Load model (.glb/.gltf/.fbx) → Assign name in modal.
P: Create 3D character? → Load model in Resources first. Then Accordion "Entities" → Category "Characters" → Assign name in modal.
P: Scene programming? → Scenes → Programming → Scene script (Rhai) or Scene logic (nodes).
P: Entity programming? → Click entity in the world → "Entity properties" modal opens → "Program entity" view → Choose Rhai script or Nodes.
P: Player controls? → Accordion "Controls" → pick character → keyboard/mouse or gamepad.
P: Save? → Save in top bar; after first save, Auto.

p: How to create a blueprint?
1. Click the entity in the world.
2. "Entity properties" modal opens → "Convert to Blueprint" button → Confirm in modal.

p: How to use a blueprint?
1. Accordion "Tools" → Quick Build button.
2. Modal window opens → pick category → pick the blueprint.
3. Click in the world to place copies.

p: How to create and use a blueprint? → Answer BOTH parts (create + use), each with numbered steps.
Create: steps from "p: How to create a blueprint?" above.
Use: steps from "p: How to use a blueprint?" above.

p: How to resize an entity? → Click entity in the world → "Entity properties" modal → "Transformations" tab → Scale (X, Y, Z).

P: Rename entity? → Click entity → "Entity properties" modal → "Edit name" (pencil) → type name → save (check).
P: Move or rotate entity? → Click entity → "Entity properties" modal → "Transformations" tab → Position or Rotation.
P: Enable physics? → Click entity → "Entity properties" modal → "Physics" tab → "Enable physics" → Dynamic/Static/Kinematic (by code).
P: Environment collision? → Click environment entity → "Entity properties" modal → "Physics" tab → "With collision".
P: Replace 3D model? → Click entity (not a blueprint instance) → "Entity properties" modal → "Replace model" button.
P: Delete entity? → Click entity → "Entity properties" modal → "Delete" → Confirm.
P: Delete multiple entities? → Multi-select in viewport → "Entity properties" modal → "Delete (N)" → Confirm.
P: 2D animation? → Click entity → "Entity properties" modal → "Animations" tab → "+ New animation" or play/edit in list.
P: Play 3D model animation? → Click entity with embedded .glb clips → "Entity properties" modal → "Animations" tab → play in list.
P: Rhai script on entity? → Click entity → "Entity properties" modal → "Program entity" tab → "New script (Rhai)".
P: Visual entity logic? → Click entity → "Entity properties" modal → "Program entity" tab → "Entity logic (nodes)".
